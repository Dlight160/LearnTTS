阶段1演讲按 **"是什么→为什么→怎么做"** 组织，全文以 **"小白视角"** 叙事——"一段文字怎么变成 .wav 文件的浮点数" 贯穿三个阶段。

**结构**：
- **1️⃣ 是什么**：音频文件的浮点数 = 声波采样（波形），频谱 = 频率视角。从波形到频谱的动机。
- **2️⃣ 为什么**：不用原始波形（维度高、相位不敏感）→ 不用线性频谱（人耳非线性）→ Mel 尺度（感知压缩，80 维够用）。
- **3️⃣ 怎么做**：音频文件（采样率/量化）→ STFT（切帧/加窗/FFT）→ Mel 滤波器组（降维）→ GL 重建收尾引出阶段2。

**每段结尾用 "小白此刻的状态" 承上启下**，保持故事线不断。

Why: 技术分享需要一条具象、可共情的主线，小白视角让三个阶段自然串联成"解决一个问题→遇到下一个问题"的递进关系。

How to apply: 所有技术分享类内容（CLAUDE.md 中的对话、QA 记录、阶段总结）都可以先用"小白视角"定义核心困惑，再组织解答。
